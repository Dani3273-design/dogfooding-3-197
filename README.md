# 温室大棚传感器数据分析程序

一个用于分析温室大棚环境传感器数据并生成可视化报告的 Python 程序。

## 功能特性

- **多维度数据采集**：支持温度、湿度、光照强度、CO2浓度、土壤湿度、土壤温度等传感器数据
- **时间序列分析**：按时间生成各维度数据的折线图，直观展示24小时变化趋势
- **智能分析注释**：为折线图添加中文说明文字，包括最高/最低值出现时间、平均值统计等
- **PDF报告输出**：自动生成包含封面、图表页和汇总页的 PDF 报告
- **数据覆盖机制**：重复运行时直接覆盖原有 PDF 报告

## 使用方法

### 1. 生成测试数据（首次运行）

```bash
python generate_test_data.py
```

该脚本会生成 720 条模拟数据（1天，每2分钟一条），模拟东北地区12月份温室大棚环境：
- 空气温度：18-28°C（受控环境）
- 空气湿度：50-95%（与温度负相关）
- 光照强度：0-55000 lux（日出07:00，日落16:30）
- CO2浓度：300-650 ppm（夜间高，白天低）
- 土壤湿度：55-75%
- 土壤温度：16-26°C

### 2. 运行分析程序

```bash
python main.py
```

程序会自动：
1. 读取 `data/sensor_data.csv` 数据
2. 进行统计分析（最大值、最小值、平均值、极值时间点）
3. 生成可视化图表
4. 输出 PDF 报告到 `output/report.pdf`

### 3. 查看报告

打开 `output/report.pdf` 查看完整的分析报告，包含：
- 封面页：报告基本信息
- 图表页：各指标的折线图及分析说明
- 汇总页：所有指标的统计数据

## 技术实现

### 数据生成逻辑

测试数据基于以下规律生成：
- **温度**：正弦曲线模拟，峰值在14:00左右，谷值在06:00左右
- **湿度**：与温度负相关，夜间高白天低
- **光照**：抛物线模拟，07:00-16:30有光照，12:00左右最强
- **CO2**：与温度负相关，夜间呼吸作用强浓度高，白天光合作用消耗
- **土壤参数**：相对稳定，小幅波动

### 分析功能

- 自动识别各指标的最高/最低值及出现时间
- 计算平均值和变化范围
- 根据指标特性生成针对性分析建议

### 可视化

- 使用 Matplotlib 绘制折线图
- 标注最高/最低值点
- 添加中文分析说明文字
- 支持中文显示（自动配置中文字体）

## 代码规范

- 采用驼峰命名规范（CamelCase）
- 所有日志输出使用英文
- 包含必要的代码注释
- 类和方法包含文档字符串

## 注意事项

1. 测试数据生成脚本仅用于程序测试，不是分析程序的功能
2. 如需使用真实传感器数据，请将数据保存为 `data/sensor_data.csv`，格式与测试数据一致
3. 报告生成时会直接覆盖原有 PDF 文件
4. 程序支持自动检测缺失的测试数据并自动生成
