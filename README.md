# 温室大棚传感器数据分析程序

## 项目简介

本程序用于分析温室大棚的传感器数据，自动生成包含可视化图表和统计分析的PDF报告。

## 功能特性

1. **多维度传感器数据分析**
   - 温度 (°C)
   - 相对湿度 (%)
   - 光照强度 (Lux)
   - CO2浓度 (ppm)

2. **时间序列可视化**
   - 生成各维度数据的点线图
   - 图表自动添加中文说明文字
   - 标注极值和变化规律

3. **PDF报告生成**
   - 包含数据统计摘要
   - 按分页展示各维度变化趋势图
   - 重复运行自动覆盖已有PDF

## 技术栈

- Python 3.9+
- pandas: 数据处理
- matplotlib: 数据可视化
- numpy: 数值计算
- reportlab: PDF报告生成

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 生成测试数据

```bash
python generate_test_data.py
```

将在 `data/` 目录下生成 `sensor_data.csv`，包含：
- 720条记录（1天数据，每2分钟一条）
- 模拟东北地区12月份室内温室大棚环境
- 数据符合自然规律（温度、湿度、光照随时间变化）

### 3. 运行分析程序

```bash
python main.py
```

生成的PDF报告位于 `output/sensor_analysis_report.pdf`

## 数据说明

测试数据模拟规律：
- **温度**：凌晨最低约18°C，中午最高约26°C，呈正弦分布
- **湿度**：与温度反向变化，白天低夜间高
- **光照**：6:00-18:00有光照，正午最强
- **CO2**：白天光合作用消耗，浓度低；夜间呼吸作用，浓度高

## 输出示例

PDF报告包含：
1. 报告封面和生成时间
2. 数据统计摘要表（最大值、最小值、平均值及对应时间）
3. 温度变化趋势图 + 说明
4. 湿度变化趋势图 + 说明
5. 光照强度变化趋势图 + 说明
6. CO2浓度变化趋势图 + 说明
